Netflix Content Analysis Using Excel, SQL Server, Python & Power BI
Developed an end-to-end Netflix Content Analytics project by integrating Excel, SQL Server, Python, and Power BI. Cleaned and transformed raw data, performed exploratory data analysis, and extracted meaningful insights on content growth, genre popularity, ratings, and country-wise distribution. Utilized SQL for data querying, Python for analysis and visualization, and Power BI to design interactive dashboards with KPIs, trend analysis, and dynamic filters. The project enabled data-driven understanding of Netflix's content library and demonstrated practical skills in data cleaning, analytics, visualization, and business intelligence.
